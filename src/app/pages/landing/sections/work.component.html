What I work on

Five areas, and the work that shows each one.

  • Cloud and release infrastructure

    • My Stream's backend on AWS: Amplify, Lambda, an AppSync GraphQL API, Cognito sign-in and Stripe billing.
    • sqlguard-mcp ships a non-root container image and a Helm chart, and its CI deploys it to a Kubernetes (kind) cluster and checks it.
    • runon's releases run its tests first, then publish to PyPI with Trusted Publishing.

  • Web and mobile products

    • My Stream, an Angular and Ionic web app.
    • Mushaf, a Quran reader on the web.
    • My Stream - القرآن الكريم, a long-running Android app on Google Play.

  • Data systems

    • atlas-graph-db, a graph database written from scratch: storage engine with a write-ahead log and crash recovery, atomic transactions, its own query language (AQL), a multi-user server and an Angular explorer.
    • sqlguard-mcp runs reads on a read-only SQLite connection.
    • Distributed state checked under faults: Raft attacked by a deterministic simulator (quorum-lab) and a CRDT fuzzed until replicas converge (crdt-notes).
    • Contracts for JSON event streams (schema-drift) and a ground model that states its uncertainty (strata).

  • Testing and developer tooling

    • noisefloor (regression testing for systems that don't give the same answer twice).
    • runon (shell programs across one machine or a group of servers over SSH).
    • Gates for dependency upgrades (permit) and alert rules (slo-proof).
    • 2,386 passing tests across sixteen public repos (October 2026).

  • AI systems

    • Agent tooling with human approval (triage-graph, sqlguard-mcp).
    • Hard limits on what an agent or planner may command: lab instruments (bench-mcp) and aircraft setpoints (geofence-guard).
    • Retrieval with citations that refuses without evidence (rag-knowledge-agent).
    • Routing across model providers with schema checks (llm-contract-router).
    • An AI publishing pipeline across 10 providers (My Stream).
