Open source

Thirty-two public repos across AI systems, data systems, developer tooling and robotics. Each waypoint is drawn with one dot per passing test: 3,292 as of October 2026.

The three ringed in magenta come first: two agent tools that stop for human approval, and a graph database built from scratch. I ran every suite between 13 and 16 October 2026, and each count matches the repo's CI. Where some tests need a service such as PostgreSQL, Redis or an Android emulator, the panel says so, and where this machine lacks something, such as ROS 2, the panel says that too.
